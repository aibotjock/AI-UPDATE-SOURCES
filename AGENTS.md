# AI UPDATE project instructions

Use this repository and the current user request for project decisions. Do not import personal history, rules, ideas or unfinished work from other conversations.

For channel or episode work, read channel/README.md, channel/continuity.json, channel/episode-formula.txt and channel/series-master-prompt.txt first. The approved description is channel/channel-description.txt; preserve its wording exactly. Later explicit user corrections take precedence over stored references.

Use references/source-registry.json, library/asset-index.json and library/INDEX.md in every episode plan. Inspect relevant source, benchmark, provenance, reproduction and correction records after those indexes. Follow channel/source-review-policy.md. Only reputable, reliable and regularly updated sources qualify; verify and record their update history before episode use. Registry membership and successful access checks do not verify claims.

The regular format has five roles. Practical lessons are occasional special segments for the best and/or new items only. Full episodes target 10–15 minutes, never less than ten, with a reason for a rare longer episode. The latest still-relevant benchmarks and necessary explanations may repeat with their original measurement dates and renewed verification.

Use actual same-day research before the script, America/New_York date/cutoff stamps, source-backed claims, genuine comparison outputs and actual usage/cost conditions. Never invent evidence or imply that prompt generation performed research, tests, narration or rendering.

Use existing resources rather than rebuilding the library. Preserve historical data and assets. Regenerate affected scenes after changes and verify final playback. Keep secrets, private account details and irrelevant user information out of the repository.

A request to generate a prompt is not permission to execute paid tests or publish video. A completed episode needs actual narration, synchronized media/captions and verified runtime/playback. A plan, preview, answer key or estimated duration cannot satisfy completion.

Keep the canonical series files versioned. Everyday model/source/asset updates can proceed within an authorized episode; changes to the approved brand, channel description, fixed segment roles or editorial boundaries require an explicit user instruction. Record changes and preserve prior snapshots.
