# Dated episode records

Use channel/generate_episode.py to create each episode's actual local generation-day folder. Follow its printed location and retain the dated record.

Preserve the generated prompt, template/source snapshots, selected asset/source IDs, verified claim ledger, raw comparison inputs/outputs and usage, script/narration timestamps, final scene manifest, captions, rendered output and playback report as production proceeds.

Pending placeholders are planning records, not evidence. Never mark a research, script or rendering gate complete before performing it. Generating files does not publish a video. Keep private account information and secrets outside Git. Respect source/media permissions when retaining or committing evidence.

Historical episode snapshots remain unchanged. Corrections, reruns and updated recommendations receive new dated records that reference the original episode.
