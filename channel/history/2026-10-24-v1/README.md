# Previous channel specification

The original channel-continuity branch remains intact. This folder preserves the canonical documents preceding the October 24, 2026 revision. The updated specification applies the user's channel rename, flexible segment menu, introductory series, browser scene player with OBS, visible source presentation, explicit fullscreen control, and stronger visual direction.

The executable generator and validator remain legacy tools until separately brought into agreement with version 2. They must not be used to assert compliance with version 2.
