# Mandatory episode resource workflow

Read channel/README.md and its canonical series references first. Follow the five regular segment roles. Practical lessons are optional special segments for best/new items only. Active sources must be reputable, reliable and regularly updated; apply channel/source-review-policy.md and retain maintenance evidence. Registry candidates and access checks are not approved content sources.

1. Read the source registry, asset index, benchmark chart source/date records, evergreen reference notes, prior reproduction records, and correction log.
2. Complete research and verification for the episode cutoff before writing the spoken script. Use the resulting evidence packet to write narration and a storyline suited to the episode; incorporate new research when there are verified changes. Accurate recurring explanations and the latest benchmark segment may repeat when useful; do not force novelty. Reuse checked production assets. Search metadata first, then load only the assets needed for the episode. Preserve asset IDs and provenance in the episode manifest.
3. Check dated evidence and current cloud availability against original sources before using a chart to recommend a model. Do not use a template as a measured result or a historical snapshot as a current ranking.
4. Use logos, images, graphics, icons, motion, SFX, and presentation components where they improve the explanation. All resource categories participate in the workflow; an episode need not display every asset or every category.
5. Give slides distinct compositions within the deck. Logos may repeat; preserve necessary visual continuity.
6. Use raw benchmark data and scripts for refreshed cross-company, category, and within-platform comparisons. Preserve exact model settings, intervals and coverage; do not fabricate universal rankings.
7. Save new reusable assets and metadata through the established repository collection workflow. Preserve catalog IDs and provenance; incorporate approved media-library updates into this continuity branch without overwriting dated episode snapshots. Record episode use and any limitations. Store prompts, outputs, settings, billed usage and calculations under reproducibility.
8. Add claim-level corrections and flag affected charts/recommendations. Update the dated comparison index and preserve historical evidence.

Create and include complete narration during episode production. Verify the spoken script and narration before final scene timing; align animation, SFX, cuts and final captions to the actual audio. Deliver the finished narrated video and separate editable audio tracks. A silent or effects-only preview does not meet full-episode completion. Produce narration, mixing and a complete playback check before delivery; report any unavailable capability as a blocker.

## Recurring evidence

Necessary recurring material may repeat across episodes, including the latest benchmark results until an update is available. On each research day, verify that the reused result is still the latest relevant published evidence and that benchmark versions and tested model configurations remain compatible. Preserve the original measurement date and separately record the new verification date; label the segment as unchanged, updated, or superseded. Reuse a checked chart, audio block or asset where appropriate, without implying that repeated evidence is new or a newly run test. Recheck narration and timings if dependent content changes.
