# Dated episode records

Use [the active production brief](../channel/production-brief.txt). The generator creates a new dated pending plan and refuses to overwrite an existing episode folder. Old prompts and snapshots here are historical records, not active instructions.

Retain selected evidence, asset provenance, actual inputs/outputs/costs when tests occur, scene timing, requested scripts and final deliverables as production proceeds. A pending plan is not research or a completed episode. New corrections and reruns reference the original record without silently changing it.
