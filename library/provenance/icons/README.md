# Cloud AI show workflow icons

320 distinct Lucide SVG icons covering cloud infrastructure, AI compute, programming, benchmark evidence, documents, media, communication, security, performance, pricing, navigation, platform features, source discovery and productivity. These are editorial workflow symbols, not company logos, model results, or benchmark evidence.

The SVGs are unchanged extracts from the official `lucide-static` npm package, version 1.55.0. Git tag 1.55.0 resolves to commit `70562c1ee1c4fdcf736fe97bc893fb8511927934`. Each asset record links to its immutable upstream SVG and includes its upstream Git blob SHA.

Retain `LICENSE-LUCIDE.txt` with copies of this collection. That upstream license includes ISC terms and the MIT terms and attribution for Feather-derived assets. Never present these icons as official brand logos.

Each file is 24 × 24 SVG with transparent background, `currentColor` stroke, no external resources and no scripts. It can be recolored or scaled for an episode as a derived asset; keep the source copy and metadata.

`assets.json` contains individual provenance and intended use. `verification.json` records distinct geometry checks and package integrity. Full-screen contact sheets are preview aids and not counted as individual assets.
