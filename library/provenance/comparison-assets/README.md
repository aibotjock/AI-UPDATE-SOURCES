# Evidence-first comparison production templates

180 original editable SVG assets, designed for 1920 × 1080 cloud-AI episodes.

All files are templates. No factual model scores, prices, outcomes, official logos, or screenshots are embedded. Replace placeholders with verified evidence. A benchmark score and a single task product must not be treated as interchangeable measures.

Categories: 30 comparison panels; 30 benchmark explainers; 30 verdicts; 30 change reports; 30 feature tutorials; 15 provenance layouts; 15 cost explanations.

## Regenerate
Committed files are in `library/graphics/panels/`. Use `library/asset-index.json`, filtered by `collection: comparison-assets`, for their metadata and hashes. The original standalone manifest was not copied. Running the preserved `generate.py` produces a separate local `assets/` bundle and `manifest.json`; deliberately import reviewed changes and update the assembled catalog before episode use.

SVG text, cards, arrows, and source-image slots remain editable. Use actual products and real screenshots when completing an episode.
