Templates, explanatory schematics and decorative visuals are not empirical evidence. Metadata, support scripts and preview derivatives do not count as separate assets. Acquisition/generation records describe exactly which source or procedure produced each asset.

## Assembled repository paths

`library/asset-index.json` is the canonical record for all 1,052 assembled assets. Filter its `assets` by `collection` instead of looking for omitted per-collection manifests. Every catalog `path` is relative to the repository root. Preserved attribution strings and source-asset bytes retain their original spelling; the public show name is **AI UPDATE**, with host credit **By: Dr. Chris**.

Original generators under this directory were copied from standalone source collections. Running them may create a separate local `assets`, `backgrounds`, `lucide`, or WAV bundle and an upstream-style manifest; that does not update the assembled catalog automatically. Build in a separate working copy and deliberately import reviewed changes, then refresh catalog hashes and verify the full library. Collection archives, source-tree downloads, upstream listings, original manifests and preview derivatives may be absent; do not infer that an acquisition check can be rerun without those inputs.

The repaired background/motion and icon preview helpers read the canonical catalog and the committed assets. They validate present files and render static previews, without claiming to reverify omitted upstream packages or real animation playback.
